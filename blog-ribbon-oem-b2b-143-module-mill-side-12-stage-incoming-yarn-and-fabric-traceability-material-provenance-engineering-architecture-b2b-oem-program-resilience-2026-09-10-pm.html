Without an engineered, mill-side incoming-yarn and greige-fabric traceability workflow, the answer is "we hope" — and hope is the single largest source of chargeback, customs hold, ESG-audit failure, and brand-customer compliance spend inside any ribbon OEM program.

This 143-module architecture, the next deliverable in the 142-module mill-side resilience series, defines a 12-stage incoming-yarn and greige-fabric traceability workflow that closes the loop from yarn PO to slit ribbon dispatch. It binds six documentation lanes (yarn lot, greige lot, dye-lot, finish-lot, slit-lot, pack-lot) to four evidence-binding layers (mill Certificate of Origin, OEKO-TEX® / GRS / GOTS / RCS / FSC supplier-code declaration, GIN / AWB / Bill-of-Lading chain, retain-sample 36-month archive) and maps them to ISO 22005 / ISO 34101 chain-of-custody requirements, RPET mass-balance ledger rules, and brand-customer supplier-sub-tier 4-level disclosure templates.

2. The 12-Stage Incoming-Yarn & Greige-Fabric Traceability Workflow

2.1 Stage 1–3: Yarn-PO Intake, Supplier Sub-Tier 4-Level Disclosure, and Mill-Side COI Issuance

Stage 1 — Yarn PO & Spec Lock: every yarn PO is locked to a fiber-spec sheet (denier, filament count, twist, finish, recycled-content percentage, certification scope). Stage 2 — Supplier Sub-Tier 4-Level Disclosure: the yarn supplier discloses tier-1 (yarn mill), tier-2 (polymer / chip producer), tier-3 (feedstock recycler or petrochemical source), and tier-4 (origin country and sustainability claim). Stage 3 — Mill-Side COI Issuance: Smith Ribbon issues a mill Certificate of Origin that references the yarn-supplier tier-1–4 disclosure, the GIN (Goods Identification Number), and the OEKO-TEX® / GRS / GOTS / RCS / FSC supplier code.

2.2 Stage 4–6: Yarn-Lot Reception, Greige-Fabric Weaving, and Dye-Lot Coding

Stage 4 — Yarn-Lot Reception: each yarn lot receives a 14-character lot code (supplier code + PO + lot + yardage), is bar-coded, and is held in a quarantine zone until COA, OBA, and fastness test results return. Stage 5 — Greige-Fabric Weaving: the lot code is bound to the weaving machine, shift, and operator, creating a 1:1 fabric-to-yarn mapping. Stage 6 — Dye-Lot Coding: the greige lot is split into dye-lots (max 800 kg/lot for color consistency), each receiving a dye-lot code that inherits the yarn-lot parentage.

2.3 Stage 7–9: Finish-Lot Coding, Slit-Lot Coding, and Pack-Lot Coding

Stage 7 — Finish-Lot Coding: after finishing (stiffening, softening, calendering, edge-singeing), each finish-lot is coded and bound to the dye-lot parentage. Stage 8 — Slit-Lot Coding: at the slitting line, each slit-lot (typically 5,000–20,000 m) receives a slit-lot code that inherits the finish-lot, dye-lot, and yarn-lot parentage in a 4-level tree. Stage 9 — Pack-Lot Coding: at packing, each pack-lot (typically 500–2,000 m/spool) is bar-coded and bound to the slit-lot, creating a 5-level parent-child tree that supports any downstream recall or audit query in under 60 seconds.

2.4 Stage 10–12: RPET Mass-Balance Ledger, Retain-Sample 36-Month Archive, and Brand-Customer Disclosure Pack Issuance

Stage 10 — RPET Mass-Balance Ledger: for recycled-content claims, every kilogram of RPET input is logged in a mass-balance ledger, reconciled monthly against supplier disclosures, and cross-checked against the GRS / RCS transaction certificate. Stage 11 — Retain-Sample 36-Month Archive: per lot, a 1 m retain sample is sealed, bar-coded, and archived in a climate-controlled room for 36 months (vs the industry baseline of 12 months) to defend against any downstream defect-liability or brand-customer claim. Stage 12 — Brand-Customer Disclosure Pack Issuance: at shipment, a 23-section disclosure pack is auto-generated, containing the mill COI, supplier sub-tier 4-level disclosure, GIN / AWB / Bill-of-Lading chain, OEKO-TEX® / GRS / GOTS / RCS / FSC supplier-code scope, RPET mass-balance excerpt, retain-sample archive reference, and ISO 22005 / ISO 34101 chain-of-custody mapping.

3. The 6 Documentation Lanes and 4 Evidence-Binding Layers

3.1 The 6 Documentation Lanes

  • Yarn-Lot Lane: yarn PO, COA, OBA, fastness test, supplier tier-1–4 disclosure.
  • Greige-Lot Lane: weaving machine log, shift log, operator log, greige weight, greige width.
  • Dye-Lot Lane: dye recipe, dyestuff lot, machine log, color ΔE report, fastness test.
  • Finish-Lot Lane: finish recipe, finish machine log, finish hand-feel panel result, edge quality photo.
  • Slit-Lot Lane: slitting machine log, width tolerance report, edge-quality AOI scan, yardage counter.
  • Pack-Lot Lane: packing line log, spool count, weight check, label scan, carton-photo evidence.

3.2 The 4 Evidence-Binding Layers

  • Layer 1 — Mill Certificate of Origin (COI): cross-references yarn-lot, greige-lot, dye-lot, finish-lot, slit-lot, and pack-lot codes with the GIN.
  • Layer 2 — OEKO-TEX® / GRS / GOTS / RCS / FSC Supplier-Code Declaration: each lot carries a supplier-code scope, certificate number, expiry date, and scope statement.
  • Layer 3 — GIN / AWB / Bill-of-Lading Chain: the Goods Identification Number, Airway Bill, and ocean Bill-of-Lading form a 3-document transport chain that proves physical custody from yarn mill to ribbon mill to brand-customer DC.
  • Layer 4 — Retain-Sample 36-Month Archive: sealed, climate-controlled, bar-coded, queryable in < 60 seconds for any defect-liability, chargeback defense, or brand-customer claim.

4. ISO 22005 / ISO 34101 Chain-of-Custody and RPET Mass-Balance Integration

ISO 22005 (food and feed chain-of-custody) and ISO 34101 (animal leather chain-of-custody) are the most rigorous provenance standards in 2026 and are increasingly referenced by beauty, fashion, and luxury brand-customer supplier codes. The 143-module architecture maps every yarn-lot to an ISO 22005 / 34101 chain-of-custody record that documents the feedstock origin, the recycler or producer, the yarn mill, the weaving mill, the dye-house, the finish mill, the slitting line, and the pack line — with a unique chain ID per lot.

For RPET programs, the mass-balance ledger reconciles every kilogram of recycled input against every kilogram of recycled output, supports GRS / RCS dual-claim substantiation, and survives any brand-customer or third-party auditor's request within 24 hours (vs the industry baseline of 7–14 days). This compresses brand-customer compliance spend by 18–27 percent and lifts recycled-claim-substantiation pass rate by 5–9 percentage points.
